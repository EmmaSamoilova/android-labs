# Лабораторна робота №3

## Дисципліна: Розробка мобільних застосувань під Android

---

## Тема

Дослідження способів збереження даних.

---

## Мета

Дослідити способи збереження даних у мобільних застосунках та набути практичні навички роботи зі сховищами даних.

---

## Завдання

Розробити Android-застосунок, який доповнює попередню лабораторну роботу можливістю збереження даних.

При натисканні кнопки "OK" необхідно:

* зберігати результат взаємодії з інтерфейсом у сховище;
* повідомляти користувача про успішність операції.

Додатково реалізувати:

* кнопку "Відкрити", яка відкриває нову Activity;
* у новій Activity відобразити всі збережені дані;
* у випадку відсутності даних відобразити відповідне повідомлення.

---

## Опис виконання роботи

У процесі виконання лабораторної роботи було розроблено мобільний застосунок, який дозволяє користувачу обирати параметри посуду та зберігати результати вибору у файл.

### Основний функціонал:

1. Користувач обирає:

   * тип посуду;
   * виробника;
   * діапазон цін.

2. При натисканні кнопки "OK":

   * формується текст результату;
   * результат записується у файл у внутрішній пам’яті пристрою;
   * користувач отримує повідомлення про успішне збереження.

3. Дані записуються у файл у режимі додавання (MODE_APPEND), що дозволяє накопичувати результати.

4. Додано кнопку "Відкрити":

   * здійснюється перехід до нової Activity;
   * у новій Activity виконується зчитування даних з файлу;
   * відображається весь вміст сховища.

5. Якщо файл порожній або відсутній:

   * відображається повідомлення про відсутність даних.

---

## Демонстрація роботи

1. Запуск застосунку
2. Введення параметрів користувачем
3. Натискання кнопки "OK"
4. Відображення повідомлення про збереження
5. Натискання кнопки "Відкрити"
6. Перехід до нової Activity
7. Відображення збережених даних
