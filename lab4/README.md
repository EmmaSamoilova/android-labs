# Лабораторна робота №4

## Дисципліна: Розробка мобільних застосувань під Android

---

## Тема

Дослідження способів роботи з медіаданими.

---

## Мета

Дослідити способи відтворення аудіо- та відеофайлів на платформі Android та отримати практичні навички роботи з інструментами обробки медіаданих.

---

## Завдання

Розробити Android-застосунок, який забезпечує відтворення медіафайлів.

Мінімальний функціонал:

* відтворення аудіофайлу;
* призупинення відтворення;
* зупинка відтворення.

Аудіофайл має зберігатися у внутрішньому сховищі застосунку.

---

## Використані технології

* Мова програмування: Java
* Середовище розробки: Android Studio
* Платформа: Android SDK (API 24+)
* Компоненти: Activity, Button, TextView
* Інструмент роботи з медіа: MediaPlayer

---

## Опис виконання роботи

У ході виконання лабораторної роботи було створено мобільний застосунок для відтворення аудіофайлу.

### Основні етапи реалізації:

1. Створено новий Android-проєкт із використанням Activity.

2. У папці ресурсів створено каталог `raw`, у якому розміщено аудіофайл `music.mp3`.

3. Реалізовано інтерфейс користувача, що містить:

   * кнопку "Play" для запуску відтворення;
   * кнопку "Pause" для призупинення;
   * кнопку "Stop" для повної зупинки відтворення.

4. Для роботи з аудіофайлом використано клас `MediaPlayer`, який забезпечує:

   * запуск відтворення (`start()`);
   * призупинення (`pause()`);
   * зупинку (`stop()` та повторну ініціалізацію).

5. Реалізовано обробку станів відтворення:

   * перевірка, чи файл вже відтворюється;
   * збереження позиції при паузі;
   * відновлення відтворення з тієї ж позиції.

6. Додано повідомлення для користувача (Toast) про стан відтворення.

---

## Демонстрація роботи

1. Запуск застосунку
2. Натискання кнопки "Play" — починається відтворення аудіо
3. Натискання кнопки "Pause" — відтворення призупиняється
4. Натискання кнопки "Stop" — відтворення зупиняється та скидається
