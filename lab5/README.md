# Лабораторна робота №5

## Дисципліна: Розробка мобільних застосувань під Android

---

## Тема

Дослідження роботи з вбудованими датчиками.

---

## Мета

Ознайомитися з можливостями вбудованих датчиків мобільних пристроїв та отримати практичні навички їх використання для збору і обробки даних.

---

## Завдання

Розробити Android-застосунок, який зчитує та відображає дані з вбудованого датчика.

Було обрано акселерометр, який дозволяє визначати прискорення вздовж трьох осей.

Додатково реалізовано обробку даних шляхом обчислення результуючої сили прискорення.

---

## Використані технології

* Мова програмування: Java
* Середовище розробки: Android Studio
* Платформа: Android SDK (API 24+)
* Компоненти: Activity, TextView
* Інструменти: SensorManager, SensorEventListener
* Датчик: акселерометр (TYPE_ACCELEROMETER)

---

## Опис виконання роботи

У ході виконання лабораторної роботи було створено застосунок, який відстежує дані акселерометра в реальному часі.

### Основні етапи реалізації:

1. Отримано доступ до системного сервісу SensorManager.

2. Отримано об'єкт акселерометра за допомогою:
   Sensor.TYPE_ACCELEROMETER

3. Реалізовано інтерфейс SensorEventListener для обробки подій датчика.

4. При отриманні нових даних:

   * зчитуються значення прискорення по осях X, Y, Z;
   * значення відображаються на екрані.

5. Додатково реалізовано обробку даних:

   * обчислення результуючої сили прискорення за формулою:

```
F = √(x² + y² + z²)
```

6. Забезпечено коректну роботу життєвого циклу:

   * підписка на датчик у методі onResume();
   * відписка у методі onPause().

---

## Демонстрація роботи

1. Запуск застосунку
2. Відображення початкових значень X, Y, Z
3. При зміні положення телефону значення змінюються
4. При русі пристрою збільшується значення сили прискорення
