# Лабораторна робота №6

## Дисципліна: Розробка мобільних застосувань під Android

---

## Тема

Розробка мобільного застосунку з використанням Інтернет-ресурсів (Web/API).

---

## Мета

Ознайомитися з можливостями використання Інтернет-ресурсів у мобільних застосунках та отримати практичні навички роботи з HTTP-запитами і обробкою JSON-даних.

---

## Завдання

Розробити Android-застосунок на довільну тему, яка не розглядалась у попередніх лабораторних роботах.

Було обрано тему:
**“Застосунок для отримання інформації про погоду”**

Функціонал застосунку:

* введення назви міста;
* отримання даних з Інтернету;
* обробка отриманих даних;
* відображення результату користувачу.

---

## Використані технології

* Мова програмування: Java
* Середовище розробки: Android Studio
* Платформа: Android SDK (API 24+)
* Компоненти: Activity, EditText, Button, TextView
* Технології: HTTP-запити, JSON
* API: wttr.in (безкоштовний сервіс погоди)

---

## Опис виконання роботи

У ході виконання лабораторної роботи було розроблено мобільний застосунок, який отримує та відображає дані про погоду для заданого міста.

### Основні етапи реалізації:

1. Реалізовано інтерфейс користувача:

   * поле введення назви міста;
   * кнопка для запиту даних;
   * поле для відображення результату.

2. При натисканні кнопки:

   * формується HTTP-запит до API;
   * виконується запит у фоновому потоці;
   * отримується відповідь у форматі JSON.

3. Отримані дані обробляються:

   * зчитуються значення температури, вологості, швидкості вітру;
   * визначається опис погодних умов.

4. Результат відображається у текстовому вигляді.

5. Реалізовано обробку помилок:

   * перевірка введення міста;
   * повідомлення у разі проблем із підключенням або даними.

---

## Демонстрація роботи

1. Запуск застосунку
2. Введення назви міста
3. Натискання кнопки "Отримати погоду"
4. Відображення погодних умов
